AHMAD CRAFT — موقع مودات وتكستشرات وإضافات ماينكرافت
=====================================================

التشغيل:
1) فك ضغط ahmad_craft_site.zip.
2) افتح index.html في متصفح الهاتف أو الكمبيوتر.
3) الموقع يعمل دون تثبيت مكتبات أو خادم.

تخصيص الموقع:
- افتح index.html بمحرر نصوص.
- غيّر عناوين وأوصاف البطاقات في قسم #cards.
- كل بطاقة تحتوي زرًا تجريبيًا. لاستبداله برابط تنزيل حقيقي:
  استبدل <button class="btn download-demo" ...>...</button>
  برابط مثل:
  <a class="btn" href="files/my-addon.mcaddon" download>تحميل</a>
- أنشئ مجلد files وضع فيه الملفات التي تملك حق توزيعها، أو استخدم روابط تنزيل مباشرة موثوقة.
- عدّل بريد التواصل YOUR-EMAIL@example.com في رابط mailto.
- عدّل اسم الملف وإصدار ماينكرافت والتوافق ومتطلبات كل إضافة بوضوح.

النشر المجاني على الإنترنت (GitHub Pages):
1) أنشئ حسابًا في github.com.
2) أنشئ مستودعًا جديدًا (Repository) واجعله Public.
3) ارفع index.html وأي مجلدات ملفات تحتاجها إلى المستودع.
4) من Settings > Pages اختر Deploy from a branch.
5) اختر الفرع main والمجلد /(root) ثم Save.
6) انتظر حتى يظهر رابط الموقع في صفحة Pages.

بديل أسهل: ارفع الملفات إلى Netlify Drop عبر app.netlify.com/drop (قد تختلف واجهة الخدمة).
ملاحظات:
- البطاقات الموجودة أمثلة تصميمية فقط، ولا تتضمن ملفات حقيقية للتنزيل.
- لا ترفع ملفات لا تملك حق إعادة توزيعها.
- لا ترفع ملفات تنفيذية أو ملفات مضغوطة غير موثوقة.
- اسم Minecraft وشعاراتها علامات تجارية لمالكها؛ هذا مشروع مستقل وغير رسمي.
